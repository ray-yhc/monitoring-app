Cron 표현식

            
Spring Scheduler 6-field cron을 사용합니다: 초 분 시 일 월 요일

            

                
                    

                        표현식
                        설명
                    

                
                
                    
0 */1 * * * *매 분 0초에 실행

                    
0 */5 * * * *5분마다 실행

                    
0 0 * * * *매 시 정각 실행

                    
0 0 9 * * MON-FRI평일 오전 9시 실행

                    
0 0 0 * * *매일 자정 실행

                
            

        


        
        

            

                URL_HEALTH_CHECK
                Health Endpoint 상태 점검
            

            
Health endpoint를 호출하여 HTTP 상태코드와 응답 본문의 status 필드 값을 점검합니다. Spring Actuator의 /actuator/health와 같은 엔드포인트에 적합합니다.

            

                

                    
Execution Param

                    

                        
필드필수설명

                        
                            
urlYHealth endpoint URL

                            
methodYHTTP 메서드 (GET)

                            
timeoutMsN타임아웃 (ms)

                            
headersNHTTP 헤더 오브젝트

                        
                    

                    

                

                

                    
Success Param

                    

                        
필드필수설명

                        
                            
expectedHttpStatusCodeY기대 HTTP 상태코드

                            
expectedStatusY응답 JSON의 status 값 (UP 등)

                        
                    

                    

                

            

            

                SUCCESS — HTTP 상태코드 일치 AND status 값 일치  | 
                FAILURE — 조건 미충족  | 
                ERROR — 연결 실패 / 타임아웃
            

        


        
        

            

                URL_RESPONSE_CHECK
                URL 응답 내용 점검
            

            
일반 URL을 호출하여 응답 상태코드, 응답 시간, 응답 본문 포함 문자열을 점검합니다.

            

                

                    
Execution Param

                    

                        
필드필수설명

                        
                            
urlY대상 URL

                            
methodYHTTP 메서드 (GET / POST)

                            
timeoutMsN타임아웃 (ms)

                            
headersNHTTP 헤더 오브젝트

                            
bodyNPOST 요청 바디

                        
                    

                    

                

                

                    
Success Param

                    

                        
필드필수설명

                        
                            
expectedHttpStatusCodeY기대 HTTP 상태코드

                            
maxResponseTimeMsN최대 허용 응답 시간 (ms)

                            
containsTextN응답 본문 포함 필수 문자열

                        
                    

                    

                

            

            

                SUCCESS — 상태코드 일치 AND 응답시간 이내 AND 포함 문자열 존재  | 
                FAILURE — 조건 미충족  | 
                ERROR — 연결 실패 / 타임아웃
            

        


        
        

            

                DB_QUERY_CHECK
                DB 쿼리 결과값 점검
            

            
DB 쿼리를 실행하여 단일 스칼라 결과값을 지정한 비교 조건으로 판정합니다. 사용 가능한 datasource key: default, module-a, module-b, module-c

            

                

                    
Execution Param

                    

                        
필드필수설명

                        
                            
dbYDatasource key

                            
queryY단일 스칼라 값을 반환하는 SQL

                        
                    

                    

                

                

                    
Success Param

                    

                        
필드필수설명

                        
                            
comparisonY비교 연산자 (하단 참조)

                            
expectedValueY기대 비교 값

                        
                    

                    

                

            

            

                SUCCESS — 쿼리 결과값이 comparison 조건 충족  | 
                FAILURE — 조건 미충족  | 
                ERROR — 쿼리 실행 오류
            

        


        
        

            

                DB_TEMPLATE_CHECK
                DB 템플릿 쿼리 점검
            

            
쿼리 결과가 STATUS, MESSAGE 컬럼 형태를 따르는 경우 사용합니다. STATUS 값으로 성공/실패를 판정하며, 점검 로직을 SQL 내에 직접 구현할 수 있습니다.

            

                

                    
Execution Param

                    

                        
필드필수설명

                        
                            
dbYDatasource key

                            
queryYSTATUS, MESSAGE 컬럼을 반환하는 SQL

                        
                    

                    

                

                

                    
Success Param

                    
Success Param은 사용하지 않습니다. 빈 오브젝트를 입력하세요.

                    

                    

                        
판정 기준

                        
SUCCESS — STATUS = 'SUCCESS' (대소문자 무시)

                        
FAILURE — STATUS = 'FAIL'

                        
ERROR — STATUS 컬럼 누락 / 결과 0건 / 쿼리 예외

                        
결과가 여러 행인 경우 첫 번째 행만 평가합니다.

                    

                

            

        


        
        

            

                ES_LOG_CHECK
                Elasticsearch 쿼리 결과 점검
            

            
Elasticsearch _search API를 호출하여 응답 JSON에서 지정한 경로의 값을 추출하고 비교 조건으로 판정합니다.

            

                

                    
Execution Param

                    

                        
필드필수설명

                        
                            
urlY_search endpoint URL

                            
methodYPOST

                            
bodyYES 쿼리 바디 (size, query 등)

                            
timeoutMsN타임아웃 (ms)

                            
headersNHTTP 헤더 (인증 등)

                        
                    

                    

                

                

                    
Success Param

                    

                        
필드필수설명

                        
                            
comparisonY비교 연산자 (하단 참조)

                            
expectedValueY기대 비교 값

                            
valuePathY응답 JSON에서 값을 추출할 경로

                        
                    

                    

                    

                        valuePath 예시:

                        hits.total.value — 전체 히트 수

                        aggregations.error_count.value — 집계 결과
                    

                

            

            

                SUCCESS — valuePath 추출값이 comparison 조건 충족  | 
                FAILURE — 조건 미충족  | 
                ERROR — 연결 실패 / valuePath 추출 실패
            

        


        
        

            

                PROM_QL_CHECK
                Prometheus PromQL 결과 점검
            

            
Prometheus /api/v1/query API를 호출하여 응답 JSON에서 지정한 경로의 값을 추출하고 비교 조건으로 판정합니다.

            

                

                    
Execution Param

                    

                        
필드필수설명

                        
                            
urlYPrometheus query endpoint

                            
methodYGET

                            
queryParams.queryYPromQL 쿼리 문자열

                            
timeoutMsN타임아웃 (ms)

                        
                    

                    

                

                

                    
Success Param

                    

                        
필드필수설명

                        
                            
comparisonY비교 연산자 (하단 참조)

                            
expectedValueY기대 비교 값

                            
valuePathY응답 JSON에서 값을 추출할 경로

                        
                    

                    

                    

                        valuePath 예시:

                        data.result[0].value[1] — 첫 번째 시계열의 현재값

                        data.result.length — 결과 시계열 개수
                    

                

            

            

                SUCCESS — valuePath 추출값이 comparison 조건 충족  | 
                FAILURE — 조건 미충족  | 
                ERROR — 연결 실패 / valuePath 추출 실패
            

        


        
        

            
comparison 값 목록

            
DB_QUERY_CHECK, ES_LOG_CHECK, PROM_QL_CHECK의 Success Param에서 사용합니다.

            

                
                    

                        값
                        조건
                        예시 (쿼리 결과 vs expectedValue)
                    

                
                
                    
EQUALS결과 == 기대값결과 1, 기대 1 → SUCCESS

                    
NOT_EQUALS결과 != 기대값결과 0, 기대 1 → SUCCESS

                    
GREATER_THAN결과 > 기대값결과 5, 기대 0 → SUCCESS

                    
GREATER_THAN_OR_EQUAL결과 >= 기대값결과 1, 기대 1 → SUCCESS

                    
LESS_THAN결과 < 기대값결과 0, 기대 1 → SUCCESS

                    
LESS_THAN_OR_EQUAL결과 <= 기대값결과 1, 기대 1 → SUCCESS

                    
CONTAINS결과 문자열에 기대값 포함결과 "OK_200", 기대 "OK" → SUCCESS
